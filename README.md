# Waifu Lab

Beyond Imagination — an independent anime entertainment project by NJX20.

## Development
Open `index.html` in a browser or serve the repository root with a static HTTP server. No build step or dependencies are required.

## Status
Responsive homepage foundation. Artwork and logo are pending. Navigation currently links to homepage sections. No backend, database, authentication or deployment is implemented.

## Deployment
The static files can be hosted on any static hosting provider. Keep credentials outside the repository.
